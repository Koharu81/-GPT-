Mirae AI API

OpenAI 호환 형식으로 Mirae AI를 호출할 수 있는 무료 게이트웨이입니다.

중요: Mirae 서버 자체에는 사용자별 토큰 사용량 제한을 두지 않습니다. 다만 실제 모델 공급자(Hugging Face Inference Providers)의 쿼터·요금·레이트리밋·모델 가용성까지 무제한으로 만들 수는 없습니다.

기본 정보

  • OpenAI 호환 엔드포인트: /v1/chat/completions
  • 모델 ID: mirae-free
  • 모델 목록: /v1/models
  • 상태 확인: /health
  • API 키 환경변수 MIRAE_API_KEY가 서버에 설정된 경우 Authorization: Bearer ...가 필요합니다.

Chat Completions

POST /v1/chat/completions

{
  "model": "mirae-free",
  "messages": [
    {"role": "user", "content": "안녕하세요"}
  ],
  "temperature": 0.7,
  "max_tokens": 700
}

응답

{
  "id": "mirae-chat",
  "object": "chat.completion",
  "model": "mirae-free",
  "choices": [{
    "index": 0,
    "message": {"role": "assistant", "content": "안녕하세요!"},
    "finish_reason": "stop"
  }]
}

Python

from openai import OpenAI

client = OpenAI(
    base_url="https://mirae.koharu.live/v1",
    api_key="YOUR_API_KEY"
)

response = client.chat.completions.create(
    model="mirae-free",
    messages=[{"role": "user", "content": "오늘 중요한 소식을 알려줘"}]
)

print(response.choices[0].message.content)

JavaScript

const response = await fetch("https://mirae.koharu.live/v1/chat/completions", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_API_KEY"
  },
  body: JSON.stringify({
    model: "mirae-free",
    messages: [{ role: "user", content: "안녕하세요" }]
  })
});

const data = await response.json();
console.log(data.choices[0].message.content);

직접 Mirae 웹앱용 API

POST /chat

{
  "message": "최신 정보를 찾아줘",
  "history": [],
  "web_search": true,
  "personality": "balanced",
  "temperature": 0.7,
  "max_tokens": 700
}

이 엔드포인트는 검색 결과와 언어 감지를 포함한 Mirae 전용 응답 형식을 반환합니다.

운영 정책

  • 공개 API를 무제한으로 열면 한 사람이 서버의 모델 쿼터를 모두 소비할 수 있으므로 실제 공개 배포에서는 API 키와 레이트리밋을 권장합니다.
  • 현재 구현은 스트리밍 응답을 제공하지 않습니다. 이후 SSE 스트리밍을 추가하면 ChatGPT와 비슷하게 글자가 생성되는 동안 바로 표시할 수 있습니다.
