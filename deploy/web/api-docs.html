Mirae AI API

계정별 API 키로 Mirae AI를 OpenAI 호환 형식으로 호출할 수 있습니다.

인증: Authorization: Bearer YOUR_API_KEY를 사용합니다. 서버에는 API 키 전체 값이 저장되지 않습니다.

기본 정보

  • /v1/chat/completions · OpenAI 호환 채팅 API
  • /v1/models · 사용 가능한 모델 확인
  • /chat · Mirae 웹앱 전용 응답
  • /chat/stream · SSE 실시간 생성
  • /health · 서버 상태 확인

Chat Completions

POST /v1/chat/completions

{
  "model": "mirae-free",
  "messages": [
    {"role": "user", "content": "안녕하세요"}
  ],
  "temperature": 0.7,
  "max_tokens": 700
}

Python

from openai import OpenAI

client = OpenAI(
    base_url="https://mirae.koharu.live/v1",
    api_key="YOUR_API_KEY"
)

response = client.chat.completions.create(
    model="mirae-free",
    messages=[{"role":"user","content":"오늘 중요한 소식을 알려줘"}]
)
print(response.choices[0].message.content)

JavaScript

const response = await fetch("https://mirae.koharu.live/v1/chat/completions", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
    "Authorization": "Bearer YOUR_API_KEY"
  },
  body: JSON.stringify({
    model: "mirae-free",
    messages: [{ role: "user", content: "안녕하세요" }]
  })
});
const data = await response.json();
console.log(data.choices[0].message.content);

웹 검색 정책

Mirae는 모든 질문에 뉴스 검색을 걸지 않습니다. 명시적인 검색 요청이나 최신·현재·실시간 정보와 뉴스·날씨·가격·환율·일정 등의 문맥이 함께 있을 때만 검색을 시도합니다. 따라서 단순한 안녕 같은 인사에는 검색 결과가 붙지 않습니다.

실시간 생성

웹앱은 /chat/stream의 SSE 이벤트로 높은 수준의 진행 상태를 표시합니다. UI에는 질문 분석 중 → 관련 정보 확인 중 → 답변 생성 중 같은 상태만 보이며, 비공개 추론 과정은 노출하지 않습니다.

스킬

로그인한 사용자는 웹앱의 설정 → 스킬에서 HTTP API 요청을 스킬로 등록할 수 있습니다. 채팅창에서 /skill 스킬이름 {"city":"천안"} 형식으로 실행할 수 있습니다.

보안: 스킬은 공개 인터넷 주소만 허용하고 로컬·사설 네트워크 주소를 차단합니다. 스킬에 넣는 인증 헤더는 민감정보가 될 수 있으니 비밀값을 필요 이상으로 등록하지 마세요.

공급자 제한

Mirae 서버에서 사용자별 앱 토큰 상한을 따로 두지 않더라도 실제 모델 공급자의 쿼터·레이트리밋·가용성까지 무제한으로 만들 수는 없습니다.
