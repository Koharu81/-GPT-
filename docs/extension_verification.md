# 확장 기능 검증 기록

검증일: 2026-08-17

대화 기록 화면과 모델 버전 화면을 데스크톱 뷰포트에서 확인했습니다. 두 화면 모두 사이드바 탐색, 큰 한글 제목, 검색·비교 영역, 빈 상태 메시지를 정상적으로 표시했습니다. 대화 기록이 없는 계정에서는 빈 상태를, 모델이 두 개 미만인 계정에서는 비교 준비 안내를 보여 주므로 초기 사용자에게도 오류 없이 안내합니다.

| 검증 대상 | 확인 결과 |
|---|---|
| 대화 이력 검색과 재사용 UI | 검색 입력과 빈 상태가 정상 표시되며, 사용자 발화는 학습 초안 재사용 동선을 제공합니다. |
| 모델 성능·응답 비교 UI | 모델 선택, 지표 비교, 동일 프롬프트 응답 비교 동선을 구현했고 모델 수가 부족할 때 안내합니다. |
| 웹 패널 타입·단위 테스트 | TypeScript 검사 및 5개 Vitest 테스트를 통과했습니다. |
| 로컬 런타임 | Python 컴파일 및 API 통합 테스트를 통과했습니다. |
| SDK | TypeScript 2개, Python 1개 테스트를 통과했습니다. |

관리형 패널의 모델 버전 목록은 각 사용자가 학습을 완료하면 채워집니다. Windows 로컬 패키지는 처음 설정한 관리자에게 번들된 `mirae-v1`, `mirae-v2` 메타데이터를 등록하므로 즉시 비교할 수 있습니다.
